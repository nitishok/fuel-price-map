# CLAUDE.md — fuel-price-map

Standing instructions for every Claude session on this project.

---

## Planning & feature work

- **Always grill before building.** For any new feature or significant change, ask
  clarifying questions until all requirements and UI/UX decisions are fully resolved
  before writing a single line of code.
- After grilling, enter plan mode and write a written plan. Wait for explicit approval
  before starting implementation.

---

## UI/UX consistency

- **Main page → city pages parity is mandatory.** Any UI or UX change made to
  `index.html` or `styles.css` must also be applied to the city-wise pages.
- City pages are generated by `scraper/generate_city_pages.py`. Re-run this script
  after every UI change and include the regenerated pages in the same commit.

---

## Testing & verification before review

- After implementing any change, verify it locally using the preview tools:
  1. Ensure a preview server is running (`preview_start` if needed).
  2. Check for console errors (`preview_console_logs`).
  3. Take a screenshot (`preview_screenshot`) to confirm visual correctness.
  4. For interactive features, use `preview_click` / `preview_fill` and snapshot the result.
- Do not skip verification. Never ask the user to check manually.

---

## Pre-push review (mandatory)

- **Never push to remote without explicit user approval.**
- Before pushing, present both:
  1. A **screenshot** of the running app showing the change.
  2. A **plain-text diff summary** — which files changed and what.
- Only push after the user says to proceed.

---

## Git & commits

- Use **Conventional Commits** prefixes: `feat:`, `fix:`, `chore:`, `data:`, `docs:`.
- Code changes and data/generated file changes may be bundled in one commit.
- Never force-push, never skip hooks, never amend a published commit.
- Commit messages should explain *why*, not just *what*.

---

## Project structure reference

| Path | Purpose |
|------|---------|
| `index.html` | Main map page |
| `app.js` | Frontend logic (versioned with `?v=N`) |
| `styles.css` | Shared styles (versioned with `?v=N`) |
| `share-card.js` | Canvas-based share card generator |
| `data.json` | Live price data (updated hourly by scraper) |
| `data.js` | Static bootstrap/seed data |
| `scraper/scrape.py` | Main price scraper |
| `scraper/generate_city_pages.py` | Regenerates all city pages from data |
| `scraper/fetch_news.py` | News feed scraper |
| `{city}/index.html` | Static city pages (auto-generated) |

---

## Cache-busting

- Bump `?v=N` on `styles.css` and `app.js` references in `index.html` whenever
  those files change.
- Bump `?v=N` on `share-card.js` whenever it changes.
